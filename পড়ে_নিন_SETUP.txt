এই zip-এ যা আছে:
১) গল্পের মাঝে ইংরেজি বলা বন্ধ (textclean), গল্পের প্লট ঠিক রাখার নিয়ম।
২) ভিডিও আরও উজ্জ্বল।
৩) স্ক্রিপ্টে যেমন লেখা, ঠিক তেমন চরিত্র তৈরি হয় (রাজা, রাজকন্যা, দৈত্য, সাদা শাড়ির মেয়ে...)।
৪) কথকের ধরন: নমুনা রেকর্ডিং মেপে তৈরি voice_style_profile.json (গতি, বিরতি, স্বর) — প্রতিটা পর্বে মিলিয়ে দেখার রিপোর্ট।
৫) পোস্টের আগে কোয়ালিটি গেট: ভিডিও ভাঙা / কালো / ছোট হলে পোস্ট হবে না; প্রতিটা পর্বের সম্পূর্ণ প্যাকেজ।
৬) পায়ের শব্দ, দৌড়, দরজার শব্দ ছবির সাথে মিলিয়ে।
৭) নতুন ঠিক করা (acceptance test দেখে): বিকেল/ভোর/সকাল/দুপুর ঠিক সময়ের আলো; "জমিদারবাড়ির বড় ঘর" এখন হলঘর;
   যে মেয়ের "চোখ লাল হয়ে ওঠে" সে ভূত — প্রথমে মানুষ, তারপর রূপ বদলায়; "দৌড়ে পালাল" এখন পুরো দৌড়;
   ভিড়ের লোকের পায়ের শব্দ কমানো।

ক) GitHub-এ রিপো খুলুন → Add file → Upload files।

   episode_ledger.py, CLAUDE.md, assets ফোল্ডার, tests ফোল্ডার, studio ফোল্ডার → Commit changes।
গ) yml ফাইল দুটো আলাদা করে: GitHub-এ .github/workflows/horror-story.yml খুলুন → পেন্সিল ✏️ → সব মুছে
   এই zip-এর ফাইলের লেখা পেস্ট করুন → Commit। একইভাবে cartoon-studio.yml।
