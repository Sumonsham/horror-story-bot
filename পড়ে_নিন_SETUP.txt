কার্টুন স্টুডিও: আপনার গল্প দিলে পুরো কার্টুন পর্ব তৈরি হবে (২৩ নভেম্বর ২০২৬)
=====================================================================

দুটো আলাদা ব্যবস্থা
------------------
১) বটের রোজকার গল্প (আগের মতোই):
   বট নিজে গল্প লেখে, কার্টুন ভিডিও বানায়, আর নির্ধারিত সময়ে YouTube আর Facebook-এ পোস্ট করে।
   বাকি সব সুবিধা আগের মতোই থাকে। এই zip-এ তাতে কোনো বদল হয়নি, শুধু কার্টুন আরও ভালো হয়েছে:
   - নতুন জায়গা: বাজার, মন্দির, পাহাড়, সমুদ্র, স্কুল, ক্লাসঘর।
   - কোনো চরিত্রের জন্য মানানসই কেউ না থাকলে নতুন চরিত্র তৈরি হয়।
   - টোটো বা অটোতে চালক থাকে।
২) কার্টুন স্টুডিও (নতুন): আপনি নিজের একটা গল্প দেন, ১২ জন সহকারী মিলে পুরো পর্ব বানিয়ে দেয়।
   এটা কিছু পোস্ট করে না। ভিডিও আর সব কাগজপত্র ডাউনলোডের জন্য তৈরি থাকে।

১২ জন সহকারী: প্রত্যেকের আলাদা কাজ, আলাদা ইনপুট, আলাদা আউটপুট ফাইল আর নিজের ভুল সামলানোর ব্যবস্থা
------------------------------------------------------------------------------------------------
০১ প্রোডাকশন ম্যানেজার: কাজের ক্রম ঠিক রাখে।
    কোনো কাজ ব্যর্থ হলে আবার চেষ্টা করে, তবে সংখ্যা সীমিত।
    মাঝপথে থেমে গেলে শেষ সফল ধাপ থেকে আবার শুরু করে।
    আগের ধাপে কিছু না বদলালে সেই কাজ আবার করে না, তাই গলা বা ছবির জন্য দুবার খরচ হয় না।
    মান পরীক্ষায় ভুল ধরা পড়লে দায়ী সহকারীকে কাজটা ফেরত দেয়।
০২ গল্প বিশ্লেষক: ধরন, মেজাজ, দর্শক, চরিত্র, জায়গা, সময়, আবহাওয়া → analysis.json
০৩ চিত্রনাট্যকার: দৃশ্য ধরে চিত্রনাট্য → screenplay.md
    গল্পটা "নাম: কথা" আকারে লেখা থাকলে লাইনগুলো যেমন আছে তেমনই থাকে।
০৪ চরিত্র পরিচালক: লাইব্রেরি থেকে মানানসই চরিত্র বাছে, দরকারে নতুন চরিত্র বানায় → casting.json
০৫ জায়গা ডিজাইনার: প্রতিটা দৃশ্যের জায়গা, সময়, আলো, আবহাওয়া, ঋতু → locations.json
০৬ পটভূমি শিল্পী: প্রতিটা জায়গার ছবি আর আসবাব → assets/backgrounds
০৭ স্টোরিবোর্ড পরিচালক: কে কোথায় দাঁড়াবে বা বসবে, কোন শট, দৃশ্য বদলের ধরন → scene_breakdown.json
০৮ গলার পরিচালক: প্রতিটা চরিত্রের নিজের গলা, প্রতিটা লাইন একবারই রেকর্ড হয় → audio/
০৯ অভিনয় পরিচালক: চরিত্রের ঢোকা, কথা অনুযায়ী হাতের ভঙ্গি → acting.json
১০ পরিবেশ পরিচালক: হাওয়া, বৃষ্টি, কুয়াশা (বৃষ্টির দিনে রোদ থাকে না) → environment.json
১১ ক্যামেরাম্যান: প্রতিটা দৃশ্য রেন্ডার করে (ক্যামেরা, ঠোঁট মেলানো, সাবটাইটেল) → scenes/
০৮খ সাউন্ড ডিজাইনার: জায়গার আওয়াজ (জল, ঝিঁঝি, ট্রেন, বাজার) আর মেজাজ অনুযায়ী মিউজিক
১১খ এডিটর: শুরুর নাম-কার্ড, দৃশ্যগুলো জুড়ে দেওয়া, শেষে "সমাপ্ত" → final_episode.mp4
১২ মান পরীক্ষক: ১৩টা পরীক্ষা করে → qc_report.md
    যেমন: চরিত্র একই আছে কিনা, সব কথা আছে কিনা, ঠোঁট মিলছে কিনা, ১৯২০x১০৮০, ২৪ fps,
    কালো ফ্রেম নেই, ছবি নড়ছে কিনা, ফাইল ঠিকমতো খোলে কিনা।

কীভাবে চালাবেন (GitHub)
-----------------------
ধাপ ১) এই zip আপলোড করুন:
       - tvtoon ফোল্ডার, tests ফোল্ডার, studio ফোল্ডার আর CLAUDE.md: Add file → Upload files → Commit।
       - নতুন yml ফাইল .github/workflows/cartoon-studio.yml: GitHub-এ Add file → Create new file,
         নাম লিখুন .github/workflows/cartoon-studio.yml, তারপর লেখাটা পেস্ট করে Commit।
ধাপ ২) আপনার গল্পটা একটা .txt ফাইলে লিখুন (যেমন amar_golpo.txt)।
       ফাইলটা studio/inbox ফোল্ডারে Upload files → Commit করলেই কাজ নিজে থেকে শুরু হয়ে যাবে।
       (চাইলে Actions → Cartoon Studio → Run workflow থেকেও চালাতে পারেন।)
ধাপ ৩) শেষ হলে Actions → সেই রান → Artifacts থেকে পর্বের ফোল্ডারটা ডাউনলোড করুন।
       ভেতরে থাকবে final_episode.mp4, screenplay.md, scene_breakdown.json, production_report.md,
       qc_report.md, audio আর assets ফোল্ডার।
গলা: স্বাভাবিকভাবে Gemini (voice = story)। পরীক্ষার জন্য voice = test দিলে শুধু Chirp।
গল্প লেখার সহজ নিয়ম: studio/example_story.txt দেখুন।
   প্রতিটা অনুচ্ছেদ একটা দৃশ্য। অনুচ্ছেদের প্রথম লাইনে কোথায় আর কখন লিখুন।
   কথা লিখুন "নাম: কথা" আকারে।

আমাকে এই চ্যাটে গল্প পাঠালে
--------------------------

গলাসহ ভিডিও চাইলে গল্পটা GitHub-এর studio/inbox-এ দিন।
