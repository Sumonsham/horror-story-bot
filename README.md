# Daily Horror Story Bot (V8)

প্রতিদিন দুপুর ২টো ও রাত ৮টায় একটা করে নতুন বাংলা ভূতের গল্প তৈরি হয়। ভিডিও, Reel, Short, Podcast ও ওয়েবসাইট সবই নিজে থেকে তৈরি ও প্রকাশ হয়। পুরো কাজ GitHub Actions-এ চলে, তাই আপনার PC বন্ধ থাকলেও কাজ থামে না। এতে কোনো paid API, paid runner বা billing ব্যবহার হয় না (ZERO_COST)।

## কীভাবে চলে

1. cron-job.org প্রতিদিন রাত ২টো, সকাল ১০টা, দুপুর ২টো ও রাত ৮টার আগে `horror-story.yml` চালু করে। cron-job.org না চালালে GitHub-এর নিজের backup ঘড়ি ৭৫ মিনিট পরে চালু করে। একই সময়ের গল্প কখনও দুবার যায় না।
2. **বিষয় বাছাই:** Telegram-এ আপনাকে কিছু পাঠাতে হয় না। bot নিজেই বিষয় খোঁজে (AUTO_DISCOVER)। উৎস: Google News, Google Trends, Wikipedia, YouTube ট্রেন্ড আর Gemini + Google Search। এরপর বিষয়গুলোকে স্কোর দেয়, আগে ব্যবহার হওয়া বিষয় বাদ দেয়, আর উৎস-পাতা নিজে খুলে মিলিয়ে দেখে। প্রতিটি গল্পে নিচের তিনটির একটি লেবেল থাকে:
   - **সত্য ঘটনা অবলম্বনে:** অন্তত ২টি আলাদা উৎস-পাতা মিলিয়ে দেখা হয়েছে।
   - **ঘটনা থেকে অনুপ্রাণিত কাল্পনিক কাহিনি:** ১টি উৎস-পাতা মিলিয়ে দেখা হয়েছে।
   - **সম্পূর্ণ কাল্পনিক গল্প:** শুধু ট্রেন্ডিং বিষয় থেকে নেওয়া, কোনো সত্য-দাবি নেই।
3. **লেখা:** গল্প লেখে Gemini। এই ধাপে আগের সব নিয়ম, সিরিজ ও বিশেষ পর্ব আগের মতোই থাকে। `assets/`-এর প্রতিটা নমুনা গল্পের জন্য আলাদা একজন "সহকারী" আছে। গল্পের বিষয় দেখে যে নমুনা সবচেয়ে মানায়, তার ধাঁচ ব্যবহার হয়।
4. **কণ্ঠ:** প্রথমে Gemini TTS (ফ্রি key) ব্যবহার হয়। সেটা শেষ হলে Chirp, তারপর Parler বা Edge।
5. **ভিডিও:** Cloudflare-এর ছবি, 2.5D animation, শব্দ, subtitle আর thumbnail মিলিয়ে তৈরি হয়।
6. **প্রকাশ:** YouTube (ভিডিও, Short, playlist, podcast), Facebook (ভিডিও, Reel, Story), Instagram Reel (সংযুক্ত থাকলে), Podcast RSS (Spotify ও Apple Podcasts এটা নিজেরা পড়ে নেয়), Telegram চ্যানেল আর ওয়েবসাইট।

| কমান্ড | কাজ |
| --- | --- |

| বন্ধ, বন্ধ ভূত ৩ দিন, চালু | ভিডিও বন্ধ বা চালু |

| ১ বদলাও, ২ বদলাও | আজকের গল্প বদলাও (আগের মতোই) |
| ধাঁচ (অডিওর caption-এ) | নতুন নমুনা গল্প |
| ধাঁচ আবার শেখো | প্রতিটা নমুনার ধাঁচ নতুন করে তৈরি |

| /topic_mode | বিষয় বাছাইয়ের মোড: AUTO_DISCOVER, TRUE_INCIDENT_PRIORITY, TRENDING_TOPIC_PRIORITY, USER_SUPPLIED বা MIXED |
| /topic বিষয় | আপনার দেওয়া বিষয় (ঐচ্ছিক) |

| /retry_publish | যেখানে প্রকাশ হয়নি, শুধু সেখানে আবার চেষ্টা |

সাধারণ বাংলায় লিখলেও bot বোঝে। যেমন: "নিজে সত্য ঘটনা খুঁজে গল্প বানাও", "ট্রেন্ডিং হরর বিষয় খুঁজে তৈরি করো", "আজকের গল্প সব প্ল্যাটফর্মে প্রকাশ করো", "Spotify আর Apple Podcasts-এর অবস্থা দেখাও"।

## সুইচ (GitHub → Settings → Secrets and variables → Actions → Variables)

এখানে কিছু না লিখলে নিরাপদ ডিফল্ট মান ব্যবহার হয়।

| Variable | ডিফল্ট | অর্থ |
| --- | --- | --- |
| `ZERO_COST_MODE` | 1 | কোনো paid API ডাকা যাবে না (`zerocost.py`) |
| `CHIRP_APPROVED` | 1 | Gemini-র কণ্ঠ শেষ হলে Chirp ব্যবহার হবে (মাসিক সীমা `CHIRP_MONTH_CAP`) |
| `AUTO_DISCOVER` | 1 | bot নিজে বিষয় খুঁজবে |
| `TOPIC_MODE` | AUTO_DISCOVER | বিষয় বাছাইয়ের মোড |
| `BACKUP_CLOCK` | 1 | GitHub-এর backup ঘড়ি চালু থাকবে |
| `YT_TREND_API` | 1 | YouTube ট্রেন্ড আসবে অফিসিয়াল API থেকে (দিনে সর্বোচ্চ ৩টি খোঁজ) |
| `APPLE_PODCAST_ID`, `SPOTIFY_SHOW_ID` | — | Podcast যাচাইয়ের জন্য (ঐচ্ছিক) |
| `FACE_ANIM` | 0 | 1 দিলে মুখের পলক ও ঠোঁট নড়া দেখা যাবে (classic মোড) |
| `ANIM_MODE` | classic | `character` দিলে নতুন চরিত্র-অ্যানিমেশন চালু হয় |
| `ANIM_QUALITY` | BALANCED | `FAST` দিলে রেন্ডার দ্রুত হয় |

## চরিত্র ও অ্যানিমেশন (ANIM_MODE)

- `classic` (ডিফল্ট): আগের মতো প্রতিটা দৃশ্যের পুরো ছবি তৈরি হয়, তারপর ক্যামেরা নড়াচড়া।
- `character`: bot নিজে চরিত্র তৈরি করে (`characters.py`)। প্রতিটা চরিত্রের একটা স্থায়ী ID থাকে, আর Neutral, Talking, Fear ও Shock মুখের ছবি তৈরি হয় (সিরিজের চরিত্রের চোখ-বন্ধ ছবিও)। ছবিগুলো স্বচ্ছ PNG হিসেবে GitHub Release "characters"-এ চিরকাল রাখা থাকে, তাই একই চরিত্র পরের গল্পে ফিরে এলে নতুন করে বানাতে হয় না। প্রতিটা জায়গার জন্য মানুষ-ছাড়া একটা পটভূমি তৈরি হয় (সেটাও পরে আবার ব্যবহার হয়)। এরপর Scene Manifest-এ (`manifest.py`) লেখা হয় কোন দৃশ্যে কে থাকবে, মুখে কী ভাব, ক্যামেরা কীভাবে নড়বে, কোন এফেক্ট, আর কণ্ঠের সময়। সেই অনুযায়ী `compositor.py` স্তর জুড়ে ভিডিও বানায়: parallax, pan, zoom, tracking, কুয়াশা, বৃষ্টি, ধোঁয়া, বাজ, চলমান ছায়া। ঠোঁট নড়া দেখানো হয় শুধু চরিত্রের আসল "Talking" ছবি থেকে, কোনো নকল ঠোঁট আঁকা হয় না।
- ছবি তৈরি না করা গেলে (ফ্রি সীমা শেষ হলে, key না থাকলে) কোডে আঁকা ছায়ামূর্তি (`silhouette.py`) ব্যবহার হয়। এর সত্যিকারের rig আছে, তাই হাত, মাথা আর পা নড়ে। তবে মুখ নেই, তাই lip-sync হয় না।
- `ANIM_QUALITY`: BALANCED (ডিফল্ট) বা FAST। ভিডিও দেরিতে তৈরি হলে নিজে থেকেই FAST-এ চলে যায়।
- রেন্ডার হয়ে যাওয়া দৃশ্য GitHub cache-এ রাখা থাকে। run মাঝপথে থেমে গেলে পরের run সেখান থেকে আবার শুরু করে।
- **Pilot:** Actions → Daily Horror Story → Run workflow → mode = `pilot`। এতে আসল চরিত্র দিয়ে ৬০ সেকেন্ডের একটা পরীক্ষামূলক ভিডিও তৈরি হয়। ভিডিও আর তার রিপোর্ট আপনার Telegram-এ আসে, কোথাও প্রকাশ হয় না। নিজের কম্পিউটারে চালাতে: `python pilot.py A`।

## Cinematic Animation Engine V1.0 (পরীক্ষামূলক)

কার্টুন-ধাঁচের চরিত্র কোডেই আঁকা হয় (`cartoon_rig.py`)। মাথা, চুল, চোখ, মণি, পলক, ভ্রু, নাক, মুখ, ঘাড়, শরীর, হাত, পা আর পোশাক সবই আলাদা অংশ, প্রতিটা আলাদা করে নড়ে। চরিত্ররা বসে, উঠে দাঁড়ায়, ঘোরে, হাঁটে (পা মাটি ছেড়ে ভাসে না), কথা বলার সময় হাত নাড়ে, শোনার সময় মাথা নাড়ে, ভয় পেলে পিছিয়ে যায়, আর পেছন ফিরে তাকায়।

চরিত্রের পাশাপাশি আরও কয়েকটা অংশ আছে:
- **ঠোঁট নড়া:** `lip_sync.py` আসল কণ্ঠের জোর আর স্বর শুনে মুখের আকার (A/E/O/M) বদলায়।
- **পরিবেশ:** `environment_animation.py` বানায় বাতাসে আলাদা আলাদা নড়া গাছের ডাল ও পাতা, ঢেউ খেলা পুকুর আর তাতে কাঁপা চাঁদের ছায়া, গোল ঢেউ, কুয়াশা, জলের ওপর ভেসে থাকা কুয়াশা, চলমান মেঘ, জোনাকি, উড়ে যাওয়া পাতা, আর হারিকেন-লণ্ঠনের কাঁপা আলো। বৃষ্টি আর বাজও আছে।
- **ক্যামেরা:** `cinematic_camera.py`-এ wide, two-shot, কাঁধের ওপর দিয়ে দেখা (OTS), close-up, প্রতিক্রিয়ার shot, reveal, চরিত্রের পিছু নেওয়া (follow), pull-out, হেলানো ক্যামেরা (dutch) আর ক্যামেরা কাঁপানো আছে।
- **পরিকল্পনা ও রেন্ডার:** `scene_planner.py` প্রতিটা দৃশ্যের JSON timeline লেখে। `animation_renderer.py` সেই timeline থেকে shot ধরে ধরে ভিডিও বানায়, প্রতিটা shot শেষ হলে checkpoint রাখে, তাই থেমে গেলে সেখান থেকেই আবার শুরু হয়।
- **মান যাচাই:** `animation_quality_check.py` তৈরি ভিডিও মেপে দেখে।
- **পরীক্ষা চালাতে:** `python animation_test.py`, অথবা GitHub-এ mode = `anim_test`।

আসল গল্পের ভিডিওতে এটা এখনও যুক্ত করা হয়নি। পরীক্ষা সফল হলে আর আপনি অনুমতি দিলে যুক্ত হবে। ছবির চরিত্র (photo) না থাকলে character মোড এখন কালো ছায়ার বদলে এই আঁকা মুখের চরিত্র ব্যবহার করে। পুরোনো ছায়ামূর্তিতে ফিরতে চাইলে `ANIM_FALLBACK=silhouette` দিন।

## গল্প-মিলের তিন সহকারী + জায়গার লাইব্রেরি (V1.1)
`ANIM_MODE` = `cartoon` দিলে প্রতিটা দৃশ্য কার্টুন ইঞ্জিনে তৈরি হয়, আর তিনটে আলাদা সহকারী দেখে নেয় যে ভিডিও গল্পের সাথে মিলছে কি না।
খালি রাখলে বা অন্য কিছু দিলে আগের মতো ছবির ভিডিও হয়। কোনো দৃশ্য ব্যর্থ হলে শুধু সেই দৃশ্যটা আগের নিয়মে তৈরি হয়।
- 🗺️ **জায়গা-সহকারী** (`location_assistant.py`): দৃশ্য কোথায় ঘটছে, সেটা ঠিক করে। জায়গাগুলো হল পুকুরপাড়, রাস্তা, জঙ্গল,
  ঘরের ভেতর/কুটির, রেলস্টেশন, শ্মশান আর রাজবাড়ি (`location_library.py`)। এর সাথে বৃষ্টি, ঝড় আর বিদ্যুৎ চমকও ঠিক করে।
  "যেন ... দিঘি"-র মতো তুলনা ধরা হয় না। লাইব্রেরিতে নেই এমন জায়গার জন্য সবচেয়ে কাছের জায়গা দেখায়, আর রিপোর্টে লেখে "কাছাকাছি বিকল্প"।
- 🎬 **কাজ-সহকারী** (`action_assistant.py`): প্রতিটা লাইন পড়ে লেখে কে, কী করছে, কোথায়, কোন অনুভূতিতে, কার দিকে, হাতে কী।
  প্রতিটা কাজ তিন ভাগের একটায় পড়ে:
  - সত্যিই এখন ঘটছে
  - শুধু করতে বলা হয়েছে
  - শুধু উল্লেখ করা হয়েছে (অতীত, পরিকল্পনা বা তুলনা)

  Gemini থাকলে Gemini পড়ে; না থাকলে নিজস্ব নিয়মে পড়ে। কোনটা ব্যবহার হয়েছে, রিপোর্টে লেখা থাকে।
- ⚖️ **মিল-সহকারী** (`match_assistant.py`): প্রতিটা কাজকে এই ভাগগুলোর একটায় রাখে:
  - MATCH: ঠিক সেটাই দেখানো হয়েছে
  - SUBSTITUTE: সবচেয়ে কাছের সৎ বিকল্প, আর রিপোর্টে লেখা থাকে কী দেখানো হল
  - MISSING: দেখানো হয়নি, নকলও করা হয়নি
  - COMMAND: শুধু বলা হয়েছে, তাই করা দেখানো হয়নি
  - MENTIONED: শুধু উল্লেখ
  - SOUND: শুধু শব্দ

  যে অ্যানিমেশন নেই, তার তালিকা রাখা হয় (`engine_ledgers/`), যাতে বোঝা যায় কোনটা আগে বানানো দরকার।
- টিম-রিপোর্টে এই তিন সহকারীর লাইন আসে। পুরো লাইন-ধরে রিপোর্ট থাকে `story_match_report.md`-এ।
- হাঁটা স্বাভাবিক গতিতে হয় (সেকেন্ডে প্রায় ১.৩ মিটার, প্রায় ২টো পা), দৌড় আরও জোরে। কখনো স্লো-মোশন হয় না।
  পেছন ফিরে তাকালে শরীর ঘোরে আর মুখ পাশ থেকে পেছনের দিকে দেখা যায়।
- টেস্ট: Actions → mode = `story_test`। আসল গল্পের লাইন থেকে ৩টে দৃশ্য বানানো হয়, আর ভিডিও ও মিলের রিপোর্ট Telegram-এ আসে।
  কিছু প্রকাশ হয় না।

## গল্প অনুযায়ী চরিত্র + কার্টুন চেহারা + স্বাভাবিক চলাফেরা (V1.2)
- 🔍 **কড়া চরিত্র-সহকারী** (`character_designer.enrich_from_story`): রাত ২টোয় গল্প লেখা হলেই কাজ শুরু করে। শুধু "look" লাইন নয়,
  পুরো গল্প থেকে প্রতিটা চরিত্রের চেহারার খুঁটিনাটি জোগাড় করে। প্রতিটা খুঁটিনাটির শব্দ গল্পে সত্যিই থাকতে হবে, নইলে বাদ যায়।
  তারপর মিলিয়ে দেখে কোন খুঁটিনাটি আঁকা হল আর কোনটা এখনো আঁকা যায় না (যেমন তামার আংটি, নূপুর)। যা আঁকা যায় না তা রিপোর্টে লেখা থাকে,
  কখনো নকল করা হয় না।
- 🧑‍🎨 **চরিত্র-নকশাকার** (`character_designer.py`): চেহারার বর্ণনা থেকে চরিত্রটা হুবহু তৈরি করে:
  - বয়স, গায়ের রং, চুলের ধরন আর রং, দাড়ি-গোঁফ, চশমা, তিলক বা সিঁদুর
  - কুর্তা, শার্ট (চেক), শাড়ি (পাড় সহ), ধুতি, প্যান্ট, পুরোনো ধাঁচের পোশাক, শাল
  - মালা, চুড়ি, ঝোলা, চুলে ফুল, গয়না, কানের দুল, কাজল
  - গড়ন আর উচ্চতা, হাতে লণ্ঠন, টর্চ বা লাঠি

  **ভূত** আঁকা হয় ভূত হিসেবেই: আধা-স্বচ্ছ, মাটি থেকে একটু ভেসে থাকে, চোখ জ্বলে (গল্পে লাল চোখ বললে লাল), চারপাশে হালকা কুয়াশা।
  নকশাগুলো গল্পের সাথে আর `assets/cartoon_cast.json`-এ চিরকালের জন্য রাখা হয়, তাই একই চরিত্র (তারানাথ, ভৈরব…) প্রতি পর্বে একই রকম দেখায়।
- 🎨 **কার্টুন চেহারা:** কালো রেখার outline, ভরাট হাত-পা, বড় মাথা, এক পাশে ছায়া। প্রতিটা হাতে পাঁচটা আঙুল, প্রতিটার দুটো গাঁট।
  গাছ, দরজা আর লণ্ঠনেরও outline আছে, মাটিতে রং-করা ছোপ।
- 🚶 **চলাফেরা-সহকারী** (`motion_director.py`): প্রতিটা নড়াচড়া আঁকার আগে মিলিয়ে দেখে আর দরকার হলে ঠিক করে:
  - হাঁটা ও দৌড়ের গতি মানুষের মতো, স্লো-মোশন বা ভেসে চলা নয়।
  - কেউ বসে থাকলে আগে উঠে দাঁড়ায়, তারপর হাঁটে।
  - উল্টো দিকে যাওয়ার আগে ঘুরে দাঁড়ায়: মাথা আগে, তারপর কাঁধ, তারপর পা।
  - কোনো ভঙ্গি হঠাৎ লাফিয়ে বদলায় না।
  - দুজন মানুষ কখনো একে অপরের গায়ে ঢুকে দাঁড়ায় না।
  - **হাত মেলানো:** ঠিক ২০০ px দূরে দাঁড়ায়, যাতে দুজনের হাত সত্যিই মেলে, তারপর তিনবার ঝাঁকায়।
  - **জড়িয়ে ধরা:** কাঁধ একটু ঘোরে, হাত পিঠের উপর যায়, মাথা কাছে ঝোঁকে।

  রেন্ডারের সময়ও শরীর জীবন্ত থাকে:
  - হাঁটা আস্তে শুরু হয়, আস্তে থামে, প্রতিটা পায়ে শরীর একটু দোলে।
  - বসার সময় সামনে ঝোঁকে।
  - দাঁড়িয়ে থাকলে আস্তে ভর বদলায়, শ্বাস নেয়।
- টেস্ট: `python motion_test.py` চালালে শুধু চলাফেরার নমুনা হয়: হেঁটে আসা, উঠে দাঁড়ানো, হাত মেলানো, জড়িয়ে ধরা, ঘুরে চলে যাওয়া।

## 2.5D কাট-আউট কার্টুন (পরীক্ষামূলক, এমনিতে বন্ধ)
**চালু করা:** Variables-এ `ART_MODE` = `cutout`। খালি রাখলে আগের কোডে-আঁকা চরিত্রই থাকে।
- 🎨 **শিল্পী:** প্রতিটা চরিত্রের জন্য Cloudflare (বটের নিজের ফ্রি অ্যাকাউন্ট) ৫টা ছবি বানায়: পুরো শরীর, আর মাথার সামনে, তিন-চতুর্থাংশ, পাশ আর ভয় পাওয়া ছবি।
  মাথার ছবিগুলো শরীরের ছবিকে নমুনা হিসেবে দেখে আঁকা হয়, যাতে একই চরিত্র থাকে। প্রতিটা জায়গার জন্য একটা খালি আঁকা পটভূমিও তৈরি হয়।
- ✂️ **কাটা আর জোড়া** (`cutout_assets.py`): পেছনের রং সরিয়ে শরীরকে মাথা, ধড়, দুই হাতের উপর-নিচ আর দুই পায়ের উপর-নিচে কাটে, জোড়ের জায়গা খুঁজে বের করে।
  - শাড়ি, ধুতি বা লম্বা পোশাক হলে কাপড়টা দুই পায়ে ভাগ হয়।
  - যে হাত শরীরের উপর দিয়ে আঁকা, সেটা অল্প নড়ে, যাতে ধড়ে "ভূতের হাত" না থাকে।
  - চোখ আর মুখ খুঁজে সেখানে পলক আর ঠোঁট-মেলানো আঁকা হয়।
- ✅ **গুণমান পরীক্ষা** (`asset_qa.py`): শরীর, মাথা, পটভূমি আর প্রতিটা দৃশ্য আঁকার আগে মাপা হয়। খারাপ ছবি সর্বোচ্চ ২ বার আবার বানানো হয়। একই চরিত্র ৬ বার ব্যর্থ হলে আর চেষ্টা হয় না, রিপোর্টে লেখা থাকে।
- ⏸️ **ফ্রি সীমা:** সীমা শেষ হলে সঙ্গে সঙ্গে থামে। যা তৈরি হয়েছে তা থেকে যায়, বাকিটা পরের রানে হয়। এক রানে সর্বোচ্চ `ART_MAX_IMAGES` (ডিফল্ট ৩০)টা ছবি।
  চরিত্রের ছবি কখনো রেফারেন্স-ছাড়া ব্যাকআপ পরিষেবা দিয়ে হয় না।
- 🗂️ **রেজিস্ট্রি:** `assets/cartoon_parts/`-এ থাকে `index.json`, ইতিহাস আর ছবিগুলো। প্রতিটা ফাইল নিরাপদভাবে লেখা হয়, তাই অর্ধেক-লেখা ফাইল থাকে না। একই চরিত্র চিরকাল একই থাকে।
- 🔁 **ব্যাকআপ পথ:** যে চরিত্রের ছবি এখনো তৈরি হয়নি বা পরীক্ষায় পাস করেনি, সে কোডে-আঁকা চেহারায় দৃশ্যে থাকে, কখনো বাদ পড়ে না। কোন চরিত্র কীভাবে আঁকা হল, তা রিপোর্টে থাকে।
- 🧪 **টেস্ট:**
  - Actions → mode = `art_test`: আসল AI ছবিতে তারানাথ, কিশোরী, মধুসুন্দরী আর কুটিরের পটভূমি তৈরি হয়। সব ছবির শিট, নমুনা ভিডিও আর রিপোর্ট Telegram-এ আসে।
  - Actions → mode = `full_test`: একটা পুরো গল্পের ভিডিও কার্টুন ইঞ্জিনে তৈরি হয়, কিছু প্রকাশ হয় না।
