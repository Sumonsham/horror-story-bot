চূড়ান্ত: এখন থেকে হরর গল্প কার্টুনে বেরোবে (২৩ নভেম্বর ২০২৬)
==========================================================

কী করা হয়েছে
-----------
১) সবার অনুমোদন: tvtoon/approvals.json-এ "_all": USER_APPROVED বসানো হয়েছে, আপনার নির্দেশে।
   ২০টা চরিত্র, নতুন যত চরিত্র আসবে, ভূতের ছদ্মবেশ আর ভূতের রূপ, সবাই অনুমোদিত। আপনাকে আর কিছু বলতে হবে না।
২) বটের আসল গল্প এখন আপনাআপনি কার্টুন হবে (ANIM_MODE=tvtoon)। রোজকার গল্পের ভিডিওতে:
   - প্রতিটা দৃশ্য কার্টুন হবে: জায়গা, দিন বা রাত, চরিত্র, ট্রেন, বাস, টোটো, ভূতের ছদ্মবেশ আর রূপ বদল সব থাকবে।
     শুরুর হুক দৃশ্যটাও কার্টুন হবে।
   - গলা বটের নিজের Gemini ভয়েস। প্রতিটা কথা ঠিক সেই মুহূর্তে চলে, যখন শোনা যায়, ঠোঁটও মেলে।
   - বাকি সব আগের মতোই: সাবটাইটেল, থাম্বনেল (লেখা আপনিই দেন), ফেসবুকের ৯:১৬ ভিডিও, ইউটিউব আর পডকাস্ট আপলোড।
   - কোনো দৃশ্যে কার্টুন তৈরিতে সমস্যা হলে সেই দৃশ্যটা পুরনো ছবির পদ্ধতিতে তৈরি হবে। ভিডিও কখনো আটকাবে না।
   - দৃশ্যের ছবির জন্য আর ছবি তৈরির সার্ভিস লাগবে না (খরচ বাঁচবে)। থাম্বনেল আগের মতোই তৈরি হয়।
৩) কার্টুন বন্ধ করতে চাইলে: GitHub → Settings → Secrets and variables → Actions → Variables
   → নতুন variable TVTOON_OFF = 1। মুছে দিলে আবার কার্টুন চালু হবে।
৪) সময়: ১৫ মিনিটের গল্পের কার্টুন তৈরি হতে প্রায় ৩০ থেকে ৪০ মিনিট বেশি লাগবে। GitHub-এর ৬ ঘণ্টার সীমার মধ্যেই।
৫) এখানে পুরো বটটা পরীক্ষামূলকভাবে (কিছু না পাঠিয়ে) চালিয়ে দেখা হয়েছে। কার্টুন দৃশ্যসহ ভিডিও তৈরি হয়েছে
   (production_dry_run.mp4)। ওই ভিডিওর গল্প আর গলা পরীক্ষার জন্য বানানো নকল জিনিস, আসল নয়।

আপলোড করার নিয়ম (এবার ফাইল একটু বেশি)
---------------------------------------
ধাপ ১) zip খুলুন।
ধাপ ২) tvtoon ফোল্ডার পুরোটা: GitHub → Add file → Upload files → টেনে দিন → Commit।
ধাপ ৩) main.py, CLAUDE.md আর tests/test_tvtoon.py: Upload files → Commit।
ধাপ ৪) দুটো yml ফাইল, একটা একটা করে: GitHub-এ ফাইলটা খুলুন → পেনসিল চিহ্ন → সব মুছে নতুন লেখা পেস্ট করুন → Commit।
       .github/workflows/horror-story.yml
       .github/workflows/tv-cartoon-sample.yml
ধাপ ৫) ব্যস। পরের নির্ধারিত গল্প থেকেই কার্টুন বেরোবে।
       আগে দেখে নিতে চাইলে: Actions → "TV Cartoon Test" → what = story_episode চালান।
       এতে বটের আজকের গল্পটা Gemini ভয়েসে কার্টুন হয়ে তৈরি হবে, কিন্তু কোথাও প্রকাশ হবে না।
